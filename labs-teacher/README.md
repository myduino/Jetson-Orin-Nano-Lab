# Myduino Jetson Lab: teacher app

Download it from the [latest release](https://github.com/myduino/Jetson-Orin-Nano-Lab/releases/latest):

| Computer | File |
|---|---|
| Windows | [myduino-jetson-lab.exe](https://github.com/myduino/Jetson-Orin-Nano-Lab/releases/latest/download/myduino-jetson-lab.exe) |
| Mac, Apple chip (M1 or newer) | [myduino-jetson-lab-mac-arm64.dmg](https://github.com/myduino/Jetson-Orin-Nano-Lab/releases/latest/download/myduino-jetson-lab-mac-arm64.dmg) |
| Mac, Intel | [myduino-jetson-lab-mac-x64.dmg](https://github.com/myduino/Jetson-Orin-Nano-Lab/releases/latest/download/myduino-jetson-lab-mac-x64.dmg) |

The programs are not kept in this repository, to keep it small.

**Mac:** the app is not signed by Apple. The first time, right-click the app, choose Open, then Open again. If the Mac says the app is "damaged", open Terminal and run `xattr -cr "/Applications/Myduino NVIDIA Jetson Orin Nano Lab.app"`, then open the app again.
