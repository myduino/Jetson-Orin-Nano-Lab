# Myduino Jetson Lab: teacher app

Download it from the [latest release](https://github.com/myduino/Jetson-Orin-Nano-Lab/releases/latest):

| Computer | File |
|---|---|
| Windows | [Myduino-Jetson-Orin-Nano-Lab.exe](https://github.com/myduino/Jetson-Orin-Nano-Lab/releases/latest/download/Myduino-Jetson-Orin-Nano-Lab.exe) |
| Mac, Apple chip (M1 or newer) | [Myduino-Jetson-Orin-Nano-Lab-mac-arm64.dmg](https://github.com/myduino/Jetson-Orin-Nano-Lab/releases/latest/download/Myduino-Jetson-Orin-Nano-Lab-mac-arm64.dmg) |
| Mac, Intel | [Myduino-Jetson-Orin-Nano-Lab-mac-x64.dmg](https://github.com/myduino/Jetson-Orin-Nano-Lab/releases/latest/download/Myduino-Jetson-Orin-Nano-Lab-mac-x64.dmg) |

The programs are not kept in this repository, to keep it small.

**Mac:** the app is not signed by Apple. The first time, the Mac says Apple could not verify it: click Done, open System Settings, Privacy & Security, scroll to Security and click Open Anyway. Or open Terminal once and run `xattr -cr "/Applications/Myduino Jetson Orin Nano Lab.app"`, then open the app.
